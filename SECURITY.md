# Security policy

## Supported version

Security fixes are made for the latest torwache release. Before reporting a problem, reproduce it
with the newest release or the current `main` branch when possible.

## Reporting a vulnerability

Send vulnerability reports to [security@torwache.com](mailto:security@torwache.com) and privacy
reports to [privacy@torwache.com](mailto:privacy@torwache.com). Do not publish exploit details,
credentials, private browsing information, or personal data in a GitHub issue.

Include the affected version, impact, and the smallest reliable reproduction you can provide.
Receipt can be acknowledged, but this free project does not promise a particular response or
remediation time. Ordinary bugs and feature requests belong in the public issue tracker.
